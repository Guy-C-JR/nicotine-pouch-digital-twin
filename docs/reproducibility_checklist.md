# Reproducibility checklist (Supplementary Methods M10)

- [ ] All priors, with sources and grades, tabulated and version-controlled.
- [ ] Random seeds fixed; Monte Carlo draw count justified by convergence diagnostics.
- [ ] Synthetic-population generator and calibration targets released.
- [ ] Every reported quantity accompanied by an uncertainty interval and dominant-assumption note.
- [ ] No empirical claim attached to illustrative outputs; figures labeled synthetic where applicable.
- [ ] Code, schema, and scenario definitions archived (e.g., Zenodo) with a DOI at submission.
- [ ] Environment captured (container/lockfile); analysis re-runnable end-to-end.
