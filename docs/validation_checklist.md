# Validation checklist (Supplementary Methods M9)

- [ ] Baseline hazards calibrated to SEER (calibration slope ≈ 1).
- [ ] Back-test reproduces historical smoking→lung and smokeless→oral cancer trends within intervals.
- [ ] Posterior predictive checks pass against held-out surveillance waves.
- [ ] External validation across ≥2 geographies.
- [ ] Competing-risk handling verified (no immortal-time artifacts).
- [ ] DAG-licensed adjustment sets used for each estimand; mediators not conditioned for total effects.
- [ ] Pre-registered failure criteria defined and checked before any forward forecast.
- [ ] Industry-funded inputs flagged and down-weighted; sensitivity to this weighting reported.
